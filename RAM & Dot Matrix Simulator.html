▦ LED Dot Matrix Display

LED ON LED OFF8 × 16 • animasi 128/128 B • posisi 0

Memory Hexadecimal

Setiap 2 digit hex adalah 1 kolom vertikal berisi 8 LED. Kolom dibaca dari kiri ke kanan. Bit 7 = LED paling atas. Jumlah kolom yang terlihat mengikuti ukuran display yang dipilih. Animasi mengubah tampilan, bukan input hex.

Isi memori (00–FF, dipisahkan spasi, koma, atau baris baru). Data seperti FF menyalakan semua LED pada kolom tersebut, sedangkan 00 mematikannya. Jika jumlah byte kurang, kolom sisanya bernilai 00.

30 / 128 B

Memori tetap 128 byte pada semua ukuran display. Pergeseran hanya mengubah posisi tampilan LED.
